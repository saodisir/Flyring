# Flyring

macOS 菜单栏启动器 / 切换器。光标旁边弹出面板，用环形、网格或放射线手势快速启动 App、打开文件、切换窗口。

## 特性
- 三种呼出面：环形（Ring）/ 网格（Grid）/ 放射线（Fingers）
- 触控板多指手势、鼠标侧键 / 中键、全局快捷键多种唤起方式
- ⌥ 悬停运行中 App 直接切换其窗口（需屏幕录制权限）
- 自托管激活码，年费 / 买断双模式
